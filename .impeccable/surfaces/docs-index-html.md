Audience and job: network engineers, NetOps, sysadmins deciding whether to install; they must see raw output become readable and leave with the install command.

## Direction contract

THESIS: The hero is the mechanism. One Cisco session crosses the page as raw gray text, passes through a glass prism and leaves in real PrismTTY colors. It refuses the split hero with a terminal screenshot beside the copy.

OWN-WORLD: Near-black #0a0b0d ground, #f2f3f5 text, #8b9099 secondary, #23252a hairlines. One refined sans for display and UI, one clean mono for output. The only saturated color anywhere is real PrismTTY output (#0099ff interfaces, #00ff00 up, bold #ff0000 down, #00ffff addresses, white prompts). The glass prism is the single optical object. No glow, no gradient blobs, no neon.

STORY: The visitor watches raw output become readable, believes it will do this on their own devices (real output, nine profiles, one shell that follows every hop, nothing stored by default), and copies the brew command.
