// what it does

        

          

            
Network-aware profiles

            

              Clean-room rules for prompts, interfaces, addresses, protocol state,
              counters, syslog severity, and common vendor terms, tuned per platform
              rather than one generic rule set.
            

          

          

            
Interactive shell wrapping

            

              Start one wrapped shell with ptty /bin/zsh, then keep your
              normal SSH, telnet, and console habits. Highlighting follows whatever
              the session becomes.
            

          

          

            
ChromaTerm-compatible rules

            

              Loads existing ChromaTerm YAML alongside native profiles, validates
              profile files, and reloads long-running sessions after config changes.
            

          

        

      


      

        

          
// dynamic profile switching

          
One wrapped shell follows the device context.

          

            PrismTTY watches login banners, prompts, and remote-jump commands, then
            re-colors the same kinds of output the way each vendor writes them.

// scope

          
Live terminal highlighting, not device management.

        

        

          

            
+ What it is

            

              A live terminal-output highlighter for shells, SSH sessions, pipes,
              and logs. It adds color to prompts, interfaces, addresses, protocol
              state, counters, severity, and common vendor terms.
            

          

          

            
− What it is not

            

              Not an NMS, a configuration tool, a source of truth, a SIEM, a log
              platform, or an inventory system. It never logs in to devices,
              collects inventory, pushes configuration, or stores operational data.
